# 草和树低模资源

41 个静态模型：6 棵完整树、3 个枝叶素材、32 个草模型。每棵树/枝叶的顶点和三角面均不超过 5,000，每个草模型的顶点和三角面均不超过 500。**计数为所有子网格之和，包含正反面及 UV/法线接缝引起的顶点拆分。**

- 树与枝叶：`trees/`，详见目录 README 和 preview_catalog.png。
- 草：`Grasses/`，详见目录 README 和 preview_catalog.png。
- 每个模型的 `.mesh`、`.material`、BMP 贴图可直接交给现有 GRE 加载器；无渲染器改动或新运行时依赖。
- 保留原比例、原点和 Y 向上约定；源模型没有骨架/动作。
- 本版本是有损低模：树干保留主干与大枝，树冠用较少的代表叶簇保持分布；草丛保留主要轮廓。近看叶簇较大、细枝和细叶减少。
- 树贴图最大 256 像素，草及独立枝叶最大 128 像素。

全套三角面：3,468,324 → 24,439（减少 99.30%）。网格、材质和贴图合计：330.60 MiB → 6.62 MiB。体积不含预览和文档。

每个模型均通过实际 GRE 加载、所有子网格合计的顶点/三角面双上限核对、法线/UV/索引检查及三个视角渲染。各目录 verification.log 为检查记录；每个模型的 preview*.png 是原生 GRE 渲染。comparison.csv 为完整前后对照，manifest.json 含导出参数与文件校验值。

仓库只保留本目录的低模，原始高模和下载 ZIP 已移出。使用时把资产路径指向本目录；从原件重新制作需另行准备原包及原始资源清单。
