## Demo 入库与并行优化验证

后续版本保持 1200×800、相同模型与纹理分辨率、Index32、GGX、法线、透明 Mip、线性色彩和曝光。没有减少发片、透明层或灯光；库仍为 CPU 光栅化。

新增分带调度器对不重叠的 16 行像素进行并行计算，保证每个像素原有绘制顺序。LUT 在采样循环直接读取只读表；排序改为搬动紧凑索引而不是整条顶点记录。调度独立由 `YMGRE_ENABLE_RASTER_DISPATCH` 裁剪，不产生核心库线程依赖。demo 默认最多 16 线程，T 切换单／多线程。

验证增加：混合透明／不透明及相同深度、逆序任务、非 16 倍数高度、RGB／线性、非 PBR 自动回退、固定工作区容量不足；真实线程池检查人物单／多线程输出一致，并与修改前五种模式／视角截图逐字节比较。新增只裁掉调度器的配置，连同原六种配置均运行全部测试。ASan/UBSan 继续使用 `detect_leaks=0`（环境限制同上）。

demo 使用 CMake 构建并直接读取 `Resource/girl`，已移除 Python 启动／打包脚本和分卷资源包。资源迁移逐文件校验，不依赖 `/tmp` 资源。独立 SDK demo 直接链接预编译库；完整／精简 SDK 继续验证四种颜色和索引组合，以及 11 项 ABI 配置检查。

本轮原始日志、CSV 和截图位于 `/tmp/ymgre-speed-results`。

### 本轮最终计时

旧版、新版、新版、旧版顺序独占运行；各 32 个固定轨道样本。旧版是本轮优化前约 800 ms 的正式库版本。随后新版单线程另测 16 个样本。编译与其他测试不与计时同时执行。

| 模式 | 中位数 | 均值 | 样本 |
|---|---:|---:|---:|
| 优化前，单线程 | 796.0 ms | 795.1 ms | 32 |
| 优化后，单线程 | 748.7 ms | 746.4 ms | 16 |
| 优化后，16 工作线程 | 136.0 ms | 136.0 ms | 32 |

整帧耗时减少 82.9%，约 5.85 倍加速，约 7.35 帧/秒。主要收益来自多核；单线程也有改善。五组截图（pixel/rgb/close/body/base）与优化前逐字节相同。此结果不等于达到 30 fps，性能依赖 CPU、核心数量、视角和透明重叠情况。

## JPG 95 / PNG 资源版本

11 张颜色图改为 JPEG 95 / 4:4:4，26 张透明、法线和 MRS 改为 PNG，分辨率保持原值。GRE 统一加载接口实测所有 PNG 解码数据与旧 BMP 逐字节一致。人物目录从约 681.5 MiB 降至约 70.5 MiB。当前 `Resource/girl/checksums.sha256` 记录压缩后文件，不包含旧 BMP 副本。

这次 JPEG 是有损改动，不能套用此前“五组画面完全一致”的结论：与 BMP 参考相比，五组画面每通道平均绝对差约 0.08～0.26（0～255），99% 通道差异不超过 2～3；近景平均差 0.15，最大差 13。近景人工查看未见明显块状或颜色变化，原有光栅化锯齿仍然存在。PNG 数据与透明度没有变化。

新增通用图片加载器，PNG/JPEG 默认可分别裁掉。测试涵盖 BMP、PNG RGB/灰度/调色板/alpha/16 位/交错/gamma 元数据、JPEG 常规/渐进/灰度、CMYK 拒绝、过大尺寸、所有截断前缀、失败保持输出和单通道加载。全功能、仅 PNG、仅 JPEG、最小配置、RGB565/Index16 配置各运行 21 项测试。ASan/UBSan 解码测试通过，LeakSanitizer 限制仍同前。完整／精简 SDK 的消费者配置检查增加到 13 项，包括两个解码开关不匹配的拒绝。

本次转换、解码一致性、渲染差异和测试记录：`/tmp/ymgre-codec-check`。解码依赖与接口见 [图片加载](image-loading.md)。

### 独立图片解码模块

`extern_lib/image_decode` 已独立于引擎；引擎侧只保留分配器、颜色布局和材质加载适配。完整、仅 PNG、仅 JPEG、最小配置以及 RGB565/index16 五组各通过 22 项测试；其中独立模块测试模拟每一次缓冲分配失败，确认输出不变且无遗留分配。ASan/UBSan 的图片、分配器和材质三项检查通过（环境限制下关闭 LeakSanitizer，分配器测试自行统计缓冲释放）。

### girl_viewer 命名及进一步压缩

示例目录、CMake 目标、可执行文件和构建目录统一为 `girl_viewer`，SDK 示例位于 `examples/girl_viewer`，开关为 `YMGRE_BUILD_GIRL_VIEWER`。贴图分辨率保持不变，颜色主要从原始 BMP 编码为 JPG90；法线和 MRS 优先 JPG95，均无色度降采样。透明图保留原始 PNG。文件从约 70.5 MiB 降到 41.6 MiB，共 29 JPG、8 PNG。

22 项测试及 girl_viewer 冒烟检查通过。与压缩前五组固定画面对比，整帧每通道平均绝对误差为 0.12～0.41 / 255，PSNR 47.0～52.9 dB（含背景，不能据此声称局部无误差）。脸部近景和半身人工检查未见明显差异。PNG 遮罩保持逐字节不变；JPG 法线／MRS 是明确接受的有损资源优化，不属于库解码行为变化。
