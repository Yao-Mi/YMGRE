# scene_baker

独立 RGB888 场景烘焙编辑器。已打通“选中物体 → UV1 烘焙 → 导出 → 回贴预览 → 保存/重开场景”。

## 构建与使用

桌面编辑器需要 SDL2、libpng、libjpeg 开发包和 C++11 编译器；PNG/JPEG 用于导入图片，导出仍使用 BMP。

```sh
cmake -S project_Demo/scene_baker -B build/.cache/configs/rgb888/index16/project_Demo/scene_baker
cmake --build build/.cache/configs/rgb888/index16/project_Demo/scene_baker -j4
./build/bin/rgb888/index16/scene_baker
```

1. 放置一个立方体，再放置点光源或聚光灯；全局光照可在检查器中调整。
2. 选中物体，在左下方选择“烘焙包含光照”（默认勾选），再点击顶部“烘焙”（也可右键“烘焙当前物体”）。不勾选时只合成基础颜色与纹理；勾选时还合成环境光、直接漫反射与当前相机位置对应的高光。
3. 点击顶部“导出模型”，在目录窗口中选择保存位置，也可新建目录。确认后输出独立资源文件夹，包含 `baked_model.mesh`、`baked_model.material` 和彩色 `texture_0.bmp`。导出使用现有烘焙光照，不重新计算；未烘焙或结果失效时，导出正常模型、材质和原贴图。
4. 视口下方显示导出的完整模型路径，点击后可全选复制。取消或导出失败不改变已有结果；未选中网格或尚未烘焙时会提示下一步。
5. 右键“切换烘焙预览”，对比实时光照和烘焙光照。
6. 保存 `.scene`，再次打开时会加载导出位置的 UV1 与贴图资源。资源路径相对于场景文件保存，搬移时需一起保留资源目录。

默认输出到当前目录的 `baked_scene/bake-XXXXXX/`。每次烘焙创建一个新目录，避免覆盖场景文件及撤销历史仍在引用的旧资源。也可指定输出根目录：

```sh
YMGRE_BAKE_DIR=/path/to/output ./build/bin/rgb888/index16/scene_baker
```

成品以 `baked_model.mesh` 为入口，可通过普通 Ogre 网格加载器直接导入。与编辑场景配套的 `baked.material` 等文件保留预览和重开场景所需的数据。输出包含：

| 文件 | 内容 |
| --- | --- |
| `baked_model.mesh` | 新 UV0 对应彩色图集，沿图集接缝拆分顶点，保留三角形形状 |
| `baked_model.material` | 引用彩色贴图；含光照时 `lighting off`，不含光照时 `lighting on` |
| `texture_0.bmp` | 基础颜色 × 原纹理，可选再乘烘焙光照；直接打开即可看到物体颜色 |
| `specular.bmp` | 当前视角的加法高光缓存，仅编辑源场景需要；成品已将其合入 `texture_0.bmp` |
| `lightmap.bmp` | 256×256 的 UV 空间光照图，可直接查看 |
| `uv1.csv` | 每个三角形每个角点的独立 UV1，不覆盖原有 UV0 |
| `baked.material` | 基础材质色、基础贴图/光照图引用、UV1 引用、采样模式和场景指纹 |
| `albedo.bmp` | 原基础纹理副本；无基础纹理时为白色图片，材质色保存在 `.material` |
| `bake_manifest.txt` | 后端、尺寸、UV 通道、光照内容和限制 |

`.material` 使用现有 Ogre 风格结构，并扩展 `lightmap`、`lightmap_uv1` 和 `lightmap_mode replace_diffuse` 等字段。通过 `SceneBake_LoadMaterial()` 加载时，同时返回基础材质和物体的光照贴图，调用者分别绑定材质与 `object->lightmap`。普通的旧材质解析器只认识基础材质，不能单独恢复 UV1 烘焙效果。旧 `.ylm` 场景引用仍可读取。

编辑源场景需保留 UV1 等辅助资源；成品只需一起复制 `baked_model.mesh`、`baked_model.material` 和 `texture_0.bmp`，它已将图集坐标写入模型 UV0。

物体几何、法线或灯光发生变化后，旧烘焙预览自动失效并提示重新烘焙。包含光照的烘焙记录材质颜色，修改颜色也需要重新烘焙；相机移动、物体改名和线框开关不会使其失效。重新烘焙失败会保留原有贴图。加载缺失、损坏或不匹配的资源时保留当前场景并显示错误。

## 实现范围

- 在 UV 空间插值世界位置与法线，计算环境光及点光源/聚光灯的直接漫反射；光照来自当前场景。
- 每个三角形一个独立图集区域，边缘留 2 像素并填充边界光照，避免邻区渗色。UV1 按角点存储，原网格索引与 UV0 保持不变。
- 高级光栅化管线对 UV1 做视景体裁剪插值与透视校正采样。烘焙预览使用基础纹理 × 已包含材质色的光照贴图 + 高光，不再次累加动态光照。
- 沿用引擎 RGB8 光照数值约定；这是 LDR 直接光照原型，不是线性 HDR 或物理 GI 烘焙。
- 首版支持单个三角网格；256 图集最多支持 1024 个三角形，复杂物体需先降低细分。多子网格、法线贴图参与烘焙、遮挡阴影和间接光尚未接入。已有的“启用阴影”背面补偿不会写入光照贴图。
- 烘焙为同步操作；首个验收场景是内置立方体。UV 展开目前按三角形均分面积，后续可换成按面积分配和合并共面区域。

旧的相机截图原型已替换为同一 UV 烘焙后端的无头示例：

```sh
./build/bin/rgb888/index16/scene_bake_cli baked_scene
```

## 可选光照与蓝色正方体验收

左下“烘焙包含光照”控制下一次烘焙，切换选项后点击“烘焙”重新生成：

- 不勾选：正方体 RGB(92,155,220) 写进 `texture_0.bmp`，材质颜色设为白色，载入后使用实时光照。
- 勾选：图集同时包含上述颜色与烘焙明暗；材质使用 Ogre `lighting off`，YMGRE 的材质解析和光栅化支持这一字段，不重复叠加光照。

不含光照的结果不因灯光编辑失效，烘焙模式随源 `.scene` 的资源引用保存。内部光照图和原基础纹理仍单独保存，供编辑预览使用。普通材质的含光照模式计算环境光、直接漫反射和固定视角高光，不包含遮挡阴影与间接光；成品图集暂不重采样法线贴图等额外材质通道。彩色图集分辨率目前为 256×256，复杂原始贴图经重新采样可能损失细节。

`color_bake_roundtrip` 使用真实复选框、烘焙和导出按钮，验证两种模式重开源场景、导出文件重新导入、蓝色像素、新 UV0 和光照开关。改变重导入场景的光强后，含光照成品像素完全不变，不含光照成品像素随之变化。

验收文件：`baked_scene/color_bake_demo/color-only-exported.scene`、`with-light-exported.scene`，同目录提供两张彩色图集和预览图。

## 高光与零光源成品

勾选“烘焙包含光照”时，编辑器使用烘焙瞬间的相机位置、镜面强度、高光指数和材质高光颜色计算点光源/聚光灯的 Blinn–Phong 高光。最终 RGB 为 `原纹理 × 基础色 × 漫反射光照 + 高光`，高光不会被基础纹理染色。导出的材质仍设置 `lighting off`，运行时不需要任何光源。

高光固定在图集上。之后移动观察相机不会丢弃烘焙结果，改变镜面强度、高光指数或材质高光色则要求重新烘焙。旧资源仍可加载，但要显示新增高光，需要重新烘焙一次。`SceneBake_CreateSurface()` 为包含材质颜色与参考视角的光照入口；`SceneBake_CreateView()` 保留旧版独立光照图接口；原无视角 `SceneBake_Create()` / `SceneBake_CreateMode()` 保留漫反射兼容行为。

`specular_bake_roundtrip` 验证高光像素、源场景重开、参数失效、无光源导入及保存重开。验收场景 `baked_scene/specular_bake_demo/glossy-no-lights.scene` 没有任何灯光，仍显示带高光的蓝色正方体；删除光源前后视口逐像素一致。同目录 `final-texture.png` 和 `editor.png` 可直接查看。

## 烘焙前后亮度一致

修复了普通蓝色立方体在强光下烘焙后明显变暗的问题。旧流程先将白色光照限制到 255，再乘材质色，会提前丢失亮区能量；新流程与实时渲染一致，先使用环境色/漫反射色计算各光源贡献，再截断到 RGB8，高光在纹理采样后相加。新资源使用 `lightmap_mode baked_color`，预览和成品导出都不会重复乘材质色；旧模式仍可读取。

`bake_brightness_preserved` 覆盖普通立方体的强光对照，修复后的验收画面烘焙前后逐像素一致。原图集已经丢失的亮区数据需要重新烘焙恢复。验收图片见 `baked_scene/export_preview_fix/strong-light/before-bake.png` 与 `after-bake.png`；同目录的上一级 `editor.png` 展示合并后的唯一导出按钮。

## 场景视口渲染器

视口左上方的 **渲染器** 下拉框可在 **光栅化**（默认）和 **光线追踪** 之间随时切换。两种模式共用场景、活动相机、材质、灯光、选择框和操作轴；切换不会修改模型、烘焙数据或撤销历史。渲染器是当前编辑器的视口选项，重新启动默认使用光栅化。

光追目前是 CPU 三角网格直接光照渲染器：BVH 加速主射线和阴影射线，支持多子网格、UV0 基础贴图、平面/平滑法线、法线贴图、环境光、点光源、聚光灯和 Blinn–Phong 高光。在光源属性中勾选 **启用阴影** 后，会检测其他物体及自身遮挡，形成硬阴影。未勾选时不发射阴影射线。光追逐像素计算光照，光栅化的逐面/逐顶点光照与它可能有平滑度差异。

移动相机、修改物体/材质/灯光或改变视口大小时，先输出粗预览，再按每帧约 12 ms 的细化预算恢复完整分辨率；旁边显示进度。静止时复用完成的画面。复杂模型和大贴图仍会增加 CPU 开销；支持镜面反射和玻璃折射递归；目前没有间接漫反射、软阴影、焦散或抗锯齿采样。

启用的烘焙贴图使用独立 UV1，并直接显示已烘焙漫反射和固定高光；导入的 `lighting off` 成品也不重复计算光照。**导出格式仍为三角网格**：普通材质沿用原烘焙方式，镜面、玻璃的含光照烘焙会额外捕获当前视角的反射、折射。要查看动态光追阴影，可在物体右键菜单关闭烘焙预览。

`scene_ray_renderer` 验证实际遮挡、深度、子网格、纹理、无光照材质、高光、烘焙图集、缓存刷新及目标尺寸变化；`scene_renderer_switch` 通过真实下拉框点击验证切换、光栅画面恢复、编辑和 Tank 导入。示例场景位于 `baked_scene/renderer_comparison/comparison.scene`，同目录的 `raster.png`、`ray.png` 和 `tank-ray.png` 是编辑器实际渲染截图。


## 镜面、玻璃与解析曲面

先把视口切为 **光线追踪**，选中模型，在右侧检查器底部点击 **材质与曲面**，选择材质和曲面后点击 **应用**。应用会立即重置光追进度并重新渲染，无需来回切换渲染器。光栅化模式隐藏此入口，普通颜色、高光等控件仍可使用；切换渲染器保留已设置的光追参数。取消不会改动对象或撤销历史。

- 原“镜面”字段现在叫 **高光强度**，继续控制直接光源高光。
- **镜面反射强度**为 0–1，默认 0.9；它控制真实场景倒影与基础着色的混合，独立于高光。
- **玻璃折射率**为 1–3，默认 1.5；透射颜色使用 `#RRGGBB`，默认白色。玻璃追踪进入/离开表面，按菲涅耳系数混合反射与透射，并处理全反射。最多递归 8 次，低贡献分支提前停止。透射颜色在进入介质时应用，当前不是按厚度吸收的体积材质。
- **解析曲面**只对内置球体和圆柱开放，支持移动、旋转和统一缩放。光追使用球面/封闭圆柱方程求交；光栅化、线框与导出继续使用已有细分网格。镜面、玻璃同样适用于三角网格；实心玻璃网格需要封闭、朝向一致，开放薄片并不等价于有厚度的玻璃。

`.scene` 保存材质类型、反射强度、折射率、透射色、解析曲面选项及网格细分。材质设置参与撤销/重做，复制对象保留这些参数。光栅化显示基础材质预览，真实反射和折射在光追模式下可见。当前光追仍使用硬阴影；玻璃的阴影没有透射着色或焦散，点光源高光使用现有 Blinn–Phong 近似。

未烘焙导出仍生成 Ogre v1.40 `.mesh` 和材质/图片，动态材质参数写入 `.material` 的 `ymgre_ray` 扩展行，可由 YMGRE 重导入。第三方 Ogre 读取器需要自行支持该扩展，几何本身仍是标准三角网格。仅烘焙颜色时也保留动态光追参数。

镜面、玻璃勾选 **烘焙包含光照** 后，以最终细分网格和 UV 图集采样，把烘焙瞬间的反射、折射冻结进贴图。源场景保留解析形状和动态材质，预览烘焙时显示匹配图集的网格；关闭烘焙预览即可再次使用解析曲面。改变其他物体、灯光或材质会使这份反射/折射烘焙失效，移动观察相机仍可查看已固定的结果。成品是 `lighting off` 的不透明彩色网格，不会继续折射后来放在背后的物体。

验收场景：`baked_scene/optics_demo/optics.scene`。其中包含镜面球、玻璃球、倾斜解析圆柱和蓝色网格立方体；`optics.png`、`material-panel.png` 展示实际视口与设置面板，`baked-source.scene` 保留玻璃烘焙的源数据。`scene_optics` 验证真实 UI 应用/取消、保存重开、复制、材质导出重载、固定视角烘焙、失效检测及无光源成品重导入；`scene_ray_renderer` 还覆盖镜面倒影、三角网格玻璃出射面、嵌套介质、相机位于玻璃内及解析圆柱旋转。

`scene_smooth_sphere` 使用普通球体和点光源，通过真实界面从已完成的网格光追切换到解析曲面，核对逐像素光照与实际显示刷新数据，并验证入口随渲染器显隐、切换保留参数。光追刚开始时的 8×8 方块是粗预览；完成状态对应逐像素结果。

## 自动 UV 展开

选中网格，在右侧 **材质 → UV 展开** 查看原有 UV，点击 **重新自动展开** 才重新生成。光栅化和光追模式都可使用；导入时保留原有 UV，坦克头等已经与纹理匹配的模型无需重新展开。

- **内置球体**：新建时即使用与“重新自动展开”一致的经纬度矩形布局；旧场景保留原 UV，直到手动重新展开。使用原地球示例的经纬度矩形布局，U 对应经度、V 对应纬度。经度接缝复制 U=0/1 顶点，两极各保留一行不同 U 的顶点，预览按地图常用的 2:1 显示。保留解析球面；网格表示和导出采用相同的参数 UV。矩形网格两极包含空间位置重合的三角形，和原地球示例一致，几何球面不变。
- **导入的不规则网格**：使用固定版本的 [xatlas](https://github.com/jpcy/xatlas) 做曲面参数化、接缝划分和图集排列，不再采用旧的逐块平面投影作为默认方法。按图集像素留出边距，各子网格共用一份图集。自动结果仍可能包含多个 UV 岛，可在编辑器中继续调整；当前不支持手工切缝或缝合。

所有 8 种内置网格新建时即生成 UV，点击“重新自动展开”得到一致布局。专用展开包括：

| 形状 | 默认 UV 布局 |
| --- | --- |
| 平面 | 一张矩形 |
| 立方体、长方体 | 六个独立方形/矩形面，保持边长比例和一致贴图密度 |
| 球体 | 经纬度矩形，沿接缝及两极拆点 |
| 圆柱 | 一张侧面矩形及两个圆形端盖 |
| 圆锥 | 按底面周长与母线长度计算的侧面扇形，另加圆形底面 |
| 圆环 | 沿大圆与管圈两条接缝展开为连续矩形，按两圈周长保持整体比例 |
| 胶囊 | 一张连续经纬布局，V 按上半球弧长、直筒长度和下半球弧长分配 |

圆柱端盖和圆锥底面保留圆形，所有岛之间留边距；胶囊、球体和圆环的曲率仍会带来参数展开固有的局部拉伸。胶囊生成器同时修复了下半球缺失赤道环、重复底极环造成的退化三角形，顶点数和三角形数保持不变。旧场景保留原胶囊几何及烘焙引用；点击“重新自动展开”才升级胶囊几何并清除旧烘焙。

应用会替换 UV0，并按接缝拆分顶点，保留法线、子网格材质和其他 UV 通道。现有纹理图案的位置可能改变，因此不是修复现有贴图的按钮；原烘焙会清除，之后可重新烘焙。非球体解析曲面转为三角网格。单对象支持最多 20000 个三角形、64 个子网格、8 套 UV；球体每向细分上限 100。失败保留原网格。

`.scene` 的 `ymgre:autoUv` 保存生成方式：0 为源 UV，1 为旧版分块投影（仅兼容旧场景），2 为球体经纬度，3 为旧版 xatlas 独立宽高归一化（兼容旧场景），4 为保留比例的 xatlas（导入网格默认），5 为其他内置形状的专用参数展开。重新加载源网格时重建对应 UV；移动、旋转、缩放保持排列，修改内置细分时重新展开。支持撤销/重做和复制。导出 `.mesh` 保存实际 UV 和接缝顶点，无需第三方读取器支持这些编辑器选项。

xatlas 的源码和 MIT 许可证固定在 `extern_lib/xatlas/`，仅桌面编辑器需要 C++11 编译器，C 渲染引擎不依赖它。单线程生成确保排列可重现。贴图图片可通过 UV 编辑器顶部的“导入图像”选择。

验证：`scene_uv` 检查新旧算法、经纬度接缝/两极、球体和圆环、UV 重叠、多个子网格、法线/额外 UV 保留，以及失败时不改动源网格；`scene_uv_editor` 检查真实 UI、Tank 的 6 套 UV、旋转缩放后保存重开、导出重导入、撤销/重做、复制和球体细分修改。实际预览及地球贴图示例位于 `baked_scene/automatic_uv/`。新版测试中坦克头从旧算法的 33 岛减少为 13 岛，圆环从 52 岛减少为 14 岛。

### 手动 UV 编辑

在 **材质 → UV 展开** 中选择 **顶点** 或 **UV 岛**。左键点击选择，空白处拖框选择；勾选“追加 / 切换选择”可多选。选择“移动 / 旋转 / 缩放”后拖动选区，也可输入 ΔU、ΔV、角度及 U/V 缩放，点击“应用数值变换”。旋转和缩放以选区包围盒中心为轴心，负缩放可以翻转。UV 岛指通过 UV 边界连接的一组面；当前没有单独三角面的选择模式。

滚轮缩放 UV 视图，右键拖动平移；“显示全部 / 显示选区”便于查看坦克头原始的小块 UV。拖动过程中只预览，松开提交，Esc 取消当前拖动。“撤销 / 重做”沿用场景历史；画布获得焦点时支持 Ctrl+A、Ctrl+Z、Ctrl+Shift+Z。相同三维位置且 UV 相同的重复顶点一起移动，接缝两侧 UV 不同的顶点独立编辑。

提交只修改 UV0，保留三维位置、法线和额外 UV 通道；为使光追和导出一致，会切换为网格曲面并清除原烘焙。保存 `.scene` 会嵌入逐三角面角点的实际 UV，重开及复制不会丢失手动修改；导出 `.mesh` 同样写入实际 UV。重新自动展开、修改内置模型细分会覆盖手动调整。

`scene_uv` 增加选择范围、旋转/非均匀缩放、预览隔离、UV 数据解析及拓扑不匹配验证；`scene_uv_editor` 增加真实控件数值变换、岛拖动与 Esc 取消、编辑器内撤销/重做、手动 UV 保存/重开、复制和导出重导入检查。预览见 `baked_scene/automatic_uv/tank-manual-uv.png`。

2026-09-11：修复矩形 xatlas 图集按宽高分别压入 0～1 导致圆柱端盖变椭圆的问题。新展开统一用图集最长边缩放 U/V，保留形状比例，正方形 UV 域可能留有空白。已有场景继续还原原 UV；点击“重新自动展开”才使用修复后的布局。`scene_uv_cylinder` 验证圆柱端盖等半径、实际 UI、变换后保存重开、导出重导入及旧场景兼容。

### UV 贴图联动预览

打开 **材质 → UV 展开**，默认左侧显示 UV、右侧显示三维贴图预览，编辑按钮位于下方；顶部 **贴图预览** 可控制预览显隐。下拉菜单提供 **棋盘格**（检查拉伸、方向和接缝）、**当前材质**（检查已有图案的位置）、**画板**和 **导入图像**。棋盘格只使用蓝白方格，不叠加红绿方向线。球体棋盘格按经纬度视图使用 2:1 图片；其他网格用正方形图片。多子网格各用自己的材质，左侧显示第一个选中顶点所属子网格的贴图，无选区时显示首个子网格。

在左侧编辑 UV 时，右侧直接读取暂存坐标，松开前就能看到变化；Esc、撤销、重做会同步恢复预览。右侧拖动旋转观察方向，滚轮缩放。预览使用独立相机和简单灯光，只显示基础材质颜色及贴图，不包含场景烘焙、镜面反射或折射。显示棋盘格不会改动实际材质、贴图文件或已有烘焙，也不进入场景修改历史。

UV 编辑器打开期间，主循环暂停被遮挡的场景相机渲染和视口刷新请求，光栅化与光追均适用；UV 窗口继续处理交互并按需更新。关闭 UV 窗口后，主视口从下一帧恢复渲染，显示最新修改。

右侧基础贴图预览使用独立光栅化管线，保持 400×400 分辨率和透视 UV 采样，避免每次交互同步完成光追。预览只复制暂存顶点和高级顶点属性，原模型、法线、材质及烘焙不被修改。左侧平移、缩放和选择只重画 UV 画布；改变 UV、预览观察方向或材质时才重算右侧图像。

`scene_uv_preview` 使用真实 UI 检查拖动中的像素变化、Esc 恢复、旋转/缩放、撤销/重做后资源引用，以及 Tank 原材质、UV 和烘焙的隔离。预览截图为 `baked_scene/automatic_uv/sphere-checker-preview.png` 和 `tank-material-preview.png`。

顶部 **应用贴图** 将当前预览所选贴图用于场景模型：选择“棋盘格”“画板”或“导入图像”时生成独立 BMP 基础贴图，选择“当前材质”时使用已有基础材质。自定义图片用于选中模型的全部子网格。应用后清除旧烘焙，场景立即显示基础贴图；支持撤销/重做。只查看预览不会应用贴图。

生成图片存放于 `baked_scene/texture-*/texture.bmp`（可用 `YMGRE_BAKE_DIR` 更改输出目录）。`.scene` 以相对路径 `ymgre:baseTexture` 引用图片，搬移场景时需一同保留；复制对象和修改内置细分也会保留贴图。使用“导出模型”会同时导出实际 UV、材质文件和贴图图片。

`scene_uv_apply` 通过真实按钮验证球体初始/重新展开一致、纯蓝白棋盘、场景显示、撤销/重做、保存重开、导出重导入、复制和细分修改，以及应用时清除烘焙、失败保留原状态和旧球体兼容。界面截图见 `baked_scene/automatic_uv/checker-applied-editor.png`。

## 图案画板与图像导入

画板复用 `extern_lib/YMGUI/project_Demo/image_edit` 的 Canvas、ColorPicker 和图层绘制算法，共用编辑器事件循环。选择 **画板** 打开空白画布；已有草稿时点击 **编辑画板** 继续编辑。选择 **当前材质 → 编辑图案** 可以从当前模型首个子网格的基础颜色和贴图开始绘制。

画板提供笔刷、橡皮、柔和笔刷、喷枪、直线、矩形、三角形、圆形、折线、多边形、填充桶和吸管。最多 4 层，各层可设置显隐、不透明度及正常、正片叠底、滤色、线性减淡混合；支持最近 8 步绘制撤销/重做。折线和多边形点击添加顶点，点回起点完成。点击 **完成绘制** 返回 UV 和三维预览，确认图案位置后点击 **应用贴图**。取消绘制或 Esc 保留进入画板前的图片和场景。

选择 **导入图像** 可读取 PNG、JPEG、BMP（每边最多 4096 像素），点击 **重新导入** 更换图片；**用画板编辑** 可在图片上绘制。导入保留原尺寸，进入画板时最长边超过 512 的图片等比缩小并提示；空白画布为 512×512，球体为 512×256。透明区域合成到白色背景，以匹配引擎 RGB 基础贴图。

完成绘制会合并图层，再次编辑从合并图开始；图层结构不写入场景文件。未应用的图案是当前对象的临时草稿。应用后保存独立 BMP，原导入图片移动或删除不影响已应用的材质；保存场景、撤销/重做以及模型导出均沿用已有贴图资源流程。打开画板时主场景相机继续暂停渲染，绘制仅更新二维画布，完成后才重算模型预览。

`scene_texture_tools` 验证 PNG/JPEG/BMP 解码、透明合成、损坏和超限图片拒绝，以及真实画板按钮、图层、形状、填充、橡皮、撤销/重做、取消、导入后编辑、场景隔离、应用、保存重开及模型导出重导入。实际界面截图见 `baked_scene/texture_tools/paint-editor.bmp` 和 `paint-model-preview.bmp`。

可复现的性能测量：设置 `SDL_VIDEODRIVER=dummy SDL_AUDIODRIVER=dummy YMGRE_UV_SELFTEST=1 YMGRE_UV_PERF=1` 运行编辑器。它分别测量 4096 面球体和 Tank 的 400×400 预览与完整 UI 旋转操作，各取 8 帧平均 CPU 耗时，不设依赖机器速度的通过阈值。本机修改前后记录见 `baked_scene/automatic_uv/preview-performance.txt`；该数据不包含主循环限帧等待，也不代表真实窗口显示帧率。

`scene_uv_primitives` 逐个验证 8 种内置形状的新建/重新展开一致、贴图预览、应用贴图、旋转缩放后场景重开、模型导出重导入、复制、烘焙重开及修改细分。`scene_uv` 检查专用展开无重叠、岛数量、端盖比例、几何/额外 UV 保留和重复展开稳定性。截图及可打开的场景位于 `baked_scene/primitive_uv/`。
